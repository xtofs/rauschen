# Rauschen

A small .NET playground for sound synthesis: a reusable class library for
pitches, notes, and WAV file writing, plus a console demo that renders a
melody (Ode to Joy) to `audio.wav` from a compact text format.

## Layout

```plain
rauschen/
├── src/
│   ├── Rauschen/          # class library with the reusable types
│   │   ├── Pitch.cs       # pitch as semitones relative to A4
│   │   ├── Note.cs        # pitch + duration in ticks (960 PPQN)
│   │   ├── Monophonic.cs  # melody text format parser
│   │   ├── WriterExtensions.cs  # WriteNote / WriteRest (sine synthesis)
│   │   └── WAV/           # low-level RIFF/WAV writing
│   ├── console/           # demo executable
│   ├── spectrum/          # demo: inverse-FFT synthesis with FftSharp
│   └── noise/             # demo: colors of noise (white, pink, brown, blue, violet)
├── scripts/
│   ├── gen_pitches.py     # generates the named-pitch constants in Pitch.cs
│   └── plot_spectra.py    # plots the spectra of the generated WAV files
├── convert.sh             # wav -> m4a via ffmpeg
└── rauschen.slnx
```

## Melody text format

A monophonic melody is a sequence of notes separated by whitespace; `|` can
be used as a visual bar line (it is ignored by the parser):

```plain
E4/4 E4/4 F4/4 G4/4 |
G4/4 F4/4 E4/4 D4/4 |
C4/4 C4/4 D4/4 E4/4 |
E4/4. D4/8 D4/2
```

Each note is `<pitch>/<duration>`:

* **pitch** — scientific pitch notation: a note letter `A`–`G`, an optional
  accidental (`#` sharp, `b` flat), and an octave digit, e.g. `E4`, `F#3`, `Bb2`.
* **duration** — the denominator of the note value: `/1` whole, `/2` half,
  `/4` quarter, `/8` eighth, `/16` sixteenth, …
  A trailing dot makes it a dotted note (×1.5), e.g. `E4/4.` is a dotted quarter.

```csharp
Note[] melody = "E4/4 E4/4 F4/4 G4/4".ParseMelody();
```

## Core types

* **`Pitch`** — a `record struct` holding semitones relative to A4 = 0
  (twelve-tone equal temperament). Provides `Frequency` (A4 = 440 Hz),
  `Octave`/`PitchClass`, parsing (`Pitch.Parse("F#3")`), and named constants
  for octaves 2–6 (`Pitch.C4`, `Pitch.Cs4`, flats as enharmonic aliases:
  `Pitch.Df4 == Pitch.Cs4`). Arithmetic is affine: `pitch + semitones`
  transposes, but two pitches cannot be added.
* **`Note`** — a `Pitch` plus a duration in integer ticks at 960 ticks per
  quarter note (960 PPQN, as used by MIDI sequencers). The fixed-point
  resolution 960 = 2⁶·3·5 keeps dotted notes, triplets, and quintuplets
  exact. `Beats` and `ToSeconds(bpm)` convert outward.
* **`WavWriter`** — writes mono 16-bit PCM WAV files on top of a generic
  RIFF chunk writer. The `WriteNote(seconds, pitch, waveform)` /
  `WriteRest(seconds)` extensions synthesize notes with a short fade in/out;
  the `Waveform` enum selects the oscillator shape (`Sine` by default,
  `Square`, `Sawtooth`, or `Triangle`).

## Colors of noise

The `noise` demo generates noise purely in the frequency domain: every audible
FFT bin gets a **uniformly random phase** (that is what makes it noise) and a
magnitude following the power envelope *P ∝ 1/f^α* — white (α = 0), pink (1),
brown (2), blue (−1), violet (−2), i.e. 0 / −3 / −6 / +3 / +6 dB per octave.
The shared `Spectrum.ToSamples` then inverse-FFTs the spectrum into PCM samples.
`scripts/plot_spectra.py` plots the resulting spectra to verify the slopes
visually. It needs numpy + matplotlib: either `uv run scripts/plot_spectra.py`
(dependencies are declared inline), or

```sh
python3 -m venv .venv
.venv/bin/pip install -r scripts/requirements.txt
.venv/bin/python scripts/plot_spectra.py
```

Without arguments it plots the demo output (`noise-*.wav`, `spectrum.wav`);
pass WAV files to plot those instead: `plot_spectra.py audio.wav -o out.png`.

## Build and run

```sh
dotnet build rauschen.slnx
dotnet run --project src/console    # writes audio.wav to the working directory
dotnet run --project src/spectrum   # writes spectrum.wav (chord from an inverse FFT)
dotnet run --project src/noise      # writes noise-white.wav ... noise-violet.wav
./convert.sh audio.wav              # optional: convert to audio.m4a (needs ffmpeg)
```

## Regenerating the pitch constants

The named constants in `Pitch.cs` are generated by a small Python script
(paste its output into the marked section of `Pitch.cs`):

```sh
python3 scripts/gen_pitches.py        # octaves 2-6 (default)
python3 scripts/gen_pitches.py 0 8    # custom octave range
```
