
# text format

## sample format Scientific pitch + duration

```plain
E4 q
E4 q
F4 q
G4 q
G4 q
F4 q
E4 q
D4 q
C4 q
C4 q
D4 q
E4 q
E4 dq
D4 e
D4 h
```

where

```plain
w = whole
h = half
q = quarter
e = eighth
s = sixteenth
dq = dotted quarter
```


## more compact text format

```plain
E4/4 E4/4 F4/4 G4/4 |
G4/4 F4/4 E4/4 D4/4 |
C4/4 C4/4 D4/4 E4/4 |
E4/4. D4/8 D4/2
```

where the length is after the / as the fraction so /4 is a quarter and /2 is a half note.
And the dot in ```E4/4.``` is a dotted quarter note.
